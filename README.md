# ShopFlow

ShopFlow is a learning e-commerce system planned as an Angular application and a set of .NET microservices.

## Status

Phase 0 repository setup is complete. See `.github/agents/microservices.agent.md` for the phased build plan.

## Prerequisites

- .NET 10 SDK
- Node.js LTS and Angular CLI
- Docker Desktop

Additional tools are needed for cloud infrastructure and deployment.
